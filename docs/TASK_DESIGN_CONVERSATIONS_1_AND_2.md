### Component 2: 对话一任务精密设计（题库系统现代化优化专项）

#### 1. 任务背景与核心使命
当前根目录 `index.html` 承载了题库系统的核心逻辑，但界面样式较繁杂（如八段数码管时钟、老旧按钮网格），做题流缺乏现代高品质质感，且存在外链 `exam_workbench.html` 等散乱耦合。对话一必须将题库系统打磨成一流的做题引擎，并为四大系统集成预留标准的通信接口。

#### 2. 核心优化清单
1. **界面视觉与布局现代化（对齐现代纯净规范）**：
   * 重构左侧边栏（`sidebarLeft`）：精简冗余部件，优化倒计时与状态筛选网格，采用统一的浅灰边框、圆角（8px）与悬浮反馈；
   * 重构顶部题库筛选栏（`chapterTitleBar`）：将原有的多层级下拉菜单重构为平滑的卡片式面包屑下拉，支持全键盘方向键快速选章、选科、选题型；
   * 移除已废弃的外链（如 `href="exam_workbench.html"`）。
2. **做题流与题目卡片核心体验升级**：
   * **题目排版**：优化题干富文本与 KaTeX 复杂公式混合排版的抗跳动（Anti-Layout Shift）机制；
   * **交互反馈**：选项点击带有平滑微动效，答案与解析揭示（Answer Reveal）采用折叠平滑展开；
   * **全键盘流强化**：`J / K` 或 `PageDown / PageUp` 平滑上下切题，`1 / 2 / 3` 或 `Z / X / C` 快速标记状态（熟练/模糊/不会），`Space` 展开解析，`Ctrl + Z` 撤销操作；
3. **架构解耦与“四维认知挂载插槽 (Cognitive Nexus Slot)”预留**：
   * 在题目卡片标题栏右侧，预留轻量插槽：
     ```html
     <div class="question-cognitive-badges" data-qid="...">
       <!-- 当题目有考点或解法元数据时自动渲染 -->
       <span class="badge badge-kp" title="对应考点">考点: 0/0型未定式</span>
       <span class="badge badge-method" title="所用解法">解法: 泰勒相消</span>
     </div>
     ```
   * 点击插槽徽章派发全局事件：
     ```javascript
     window.dispatchEvent(new CustomEvent('open-cognitive-view', {
       detail: { qid, chapterId, kpId, methodId }
     }));
     ```
   * 为后续无缝呼出考点与解法大纲彻底铺平道路。
4. **性能与数据落盘保障**：
   * 优化单页渲染与虚拟滚动性能；
   * 保障与 `storage_sync.js`、`kaoyan_tiku_data.json` 本地落盘的高可靠性。

#### 3. 验收标准 (DoD)
* 根目录 `index.html` 界面现代化改造完成，所有题库功能（真题浏览、刷题、答题、错题本、同步）100% 正常；
* 运行 `node tests/cdp_e2e_tests.js` 全量通过；
* 无控制台报错，无死链。

### Component 3: 对话二任务精密设计（第一章核心技术前沿研发专项）

#### 1. 任务背景与核心使命
以 `题库/最终笔记/data/第1章_函数与极限.md` 为真实的业务载体，攻关突破“画板式无限画布、有向网状关联线、考点中枢高维联结、同步块镜像内联、MathViz 几何动图”这套最关键的前沿技术链，在第一章上形成高保真原型。

#### 2. 输入资源
* 知识点底座：[`最终笔记/data/第1章_函数与极限.md`](file:///d:/tj/822/考研题库/最终笔记/data/第1章_函数与极限.md)（已包含函数性质、极限定义、连续性及 `> 同步块` 标记）；
* 考点与解法：`题库/研砖/pojue_lectures.json` 中 `GS01` 章节（由极限值反推、分左右极限、等价代换、泰勒展开、洛必达 5 大解法）；
* 几何动图：`题库/研砖/kaogang_figures.json` 中的极限与连续可视化 DSL。

#### 3. 核心研发与交付清单
1. **画板无限空间与三区域模块化排版 (Spatial Layout)**：
   * 构建无限平移与缩放画布（Pan-Zoom Canvas，基于纯原生 SVG/CSS Transform，零冗余重型依赖）；
   * 空间横向划分为清晰的三大区域：
     * **左侧【知识点区域】**：呈现由《第1章_函数与极限.md》解析出的章节树状大纲与定理推导；
     * **中央【考点中枢区域】**：放置第一章核心考点卡片（如“0/0型未定式求值”、“极限反求参数”、“分段点连续性判定”）；
     * **右侧【解法流程区域】**：放置第一章 5 大标准解法步骤流程卡。
2. **考点高维中枢与有向贝塞尔连线 (Directed Bézier Connectors)**：
   * 考点卡片向左引出有向贝塞尔曲线连接知识点，向右引出有向贝塞尔曲线连接解法；
   * 点击连线镜头平滑运镜至对应模块；
   * **Focus Resonance（拓扑聚焦高亮）**：点击任一考点，与其相连的知识点与解法高亮，其他无关卡片透明度降为 15%。
3. **“同步块 (Synced Block)”引用镜像内联组件**：
   * 实现同步块镜像语法解析（识别《最终笔记》中的 `> 同步块：...` 标记）；
   * 在考点卡片上支持一键展开“同步引用镜像”：直接在考点卡片内原地渲染对应的知识定理公式与解法步骤 1-2-3，视线无需左右跳跃。
4. **参数化数学几何动图小部件 (MathViz Widget)**：
   * 实现一个超轻量级内联数学可视化渲染器（支持 2D 曲线切线逼近、间断点跳跃动效、二重积分区域示意）；
   * 在《第1章》知识大纲的“重要极限”和“导数几何意义”下方成功内联渲染，支持参数拖拽。
5. **纯白大纲沉浸视图与 KaTeX 预览胶囊复用**：
   * 将在 `mindmap-sandbox` 验证成功的纯白全屏大纲模式与打字实时公式预览胶囊完整封装为通用组件。

#### 4. 验收标准 (DoD)
* 产出第一章完整可交互的技术原型组件库；
* 编写自动化 CDP E2E 测试脚本，全量验证：三区域加载、贝塞尔连线绘制、Focus Resonance 聚焦高亮、同步块展开、MathViz 动图渲染；
* 形成干净、模块化、即插即用的 JS/CSS 包，供后续对话直接引入根 `index.html`。
